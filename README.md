# 🏡 Mortgage Refinance Break-Even Calculator

An interactive, privacy-first financial tool designed to determine if refinancing a home mortgage yields net positive financial return. Calculates break-even timeline in months, monthly principal & interest savings, lifetime interest saved, and models rolling closing costs into loan balances.

## 🚀 Key Features

- **Break-Even Point Calculation:** Computes the exact number of months needed to recover upfront closing costs.
- **Monthly Cash Flow Comparison:** Real-time principal & interest payment difference between current loan and refinance offer.
- **Total Interest Saved:** Computes net lifetime interest savings across the full loan lifecycle.
- **Rolling Closing Costs:** Toggle option to roll closing fees directly into the new principal balance.
- **Payback Horizon Progress Bar:** Color-coded visual timeline comparing break-even horizon against standard 5-7 year homeowner tenure.
- **Dark Glassmorphism UI:** Modern, responsive design optimized for mobile and desktop screens.
- **Zero External Dependencies:** Native HTML5, CSS3, and JavaScript.
